# Humanoid Interaction Locomanipulation Data Engine

The initial 17-entry reading list is preserved here. The main README uses five broad research directions and a small set of examples. / 此处保留初版 17 项资源；首页按五个大方向展示少量示例。

## English

Methods and resources for acquiring, reconstructing, retargeting, and augmenting interaction demonstrations. Human-avatar methods and human-only datasets are related foundations; their inclusion does not imply real-robot deployment.
